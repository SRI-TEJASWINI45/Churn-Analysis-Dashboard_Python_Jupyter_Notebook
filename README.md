# Churn Analysis Dashboard_Python
Interactive Python dashboard showing customer churn insights with Plotly.
An interactive Python dashboard analyzing **customer churn** using Plotly and Pandas.

## Overview
This project provides insights into **why customers churn** and highlights **retention trends**. The dashboard includes professional charts and tables with clear formatting, helping businesses make data-driven retention decisions.

## Files
- `Churn_Dashboard.ipynb` → The Jupyter Notebook with the full analysis, interactive charts, and actionable insights.  
- `Churn_Cleaned.csv` → Cleaned dataset used for analysis (optional to include).

## Features
- **Overview Table:** Professional table showing sample data with serial numbers and borders.  
- **Churn Distribution:** Interactive pie/donut chart showing churn vs retained customers.  
- **Churn by Contract & Payment:** Bar charts highlighting high-risk contract types and payment methods.  
- **Tenure & Monthly Charges Analysis:** Box plots showing trends between customer tenure, monthly charges, and churn.  
- **Actionable Insights:** Key recommendations to reduce customer churn.

## Technologies
- Python  
- Pandas  
- Plotly (for interactive charts)
